# Codex 모델 호출 메타데이터 감사

감사 범위는 **2026-10-09 10:10:00~13:22:45 KST**이며, UTC로는 **01:10:00~04:22:45**다. 로컬 Codex 로그의 모델 선택·스트림·샘플링 메타데이터만 확인했다.

최신 사용자 지시에 따른 판정 기준은 **GPT 계열 모델은 허용하며, GPT 외 모델만 문제로 판단한다**는 것이다. 따라서 확인된 **`gpt-6.1-sol`과 `gpt-6-luna`는 모두 허용 범위**다. 고정 감사 범위에서 **GPT 외 모델 실행 증거는 없었다.** Codex 내부 로그에 `gpt-6.1-sol` 이외의 `gpt-6-luna` 실행 기록이 있다는 사실은 유지하되, 이는 문제로 분류하지 않는다.

모델 이름의 참고 자료로 [공식 GPT-6 Luna 문서](https://developers.openai.com/api/docs/models/gpt-6-luna)를 확인했다. 공식 문서는 모델 설명의 출처이며, 이 컴퓨터의 호출 여부는 아래 로컬 로그에서만 판단했다.

| 증거 종류 | `gpt-6.1-sol` | `gpt-6-luna` |
|---|---:|---:|
| JSONL `turn_context` 모델 선택 기록 | 57건 | 0건 |
| DB `codex_core::stream_events_utils` 모델 메타데이터 | 1,976행 | 72행 |
| 위 스트림 로그 중 `output_item` 포함 | 982행 | 36행 |
| DB `codex_core::session::turn`의 `sampling` 기록 | 444행 | 23행 |

JSONL 7개에서 확인한 `session_meta.model_provider`는 모두 `openai`였다. 감사 당시 `config.toml`의 모델은 `gpt-6.1-sol`, 추론 수준은 `xhigh`였다. 설정과 `turn_context`는 **선택 증거**이며, DB의 스트림·샘플링 기록은 **실행 관련 증거**로 구분했다. 허용 모델인 `gpt-6-luna`의 스트림·샘플링 기록 시각은 **10:17:13~12:47:53 KST**다.

증거 경로와 재현 기준:

- `~/.codex/sessions/2026/10/09/*.jsonl`: 수정 시각으로 후보 파일을 선별하고, 각 레코드의 `timestamp`를 고정 감사 범위로 제한했다. `turn_context.payload.model`과 `session_meta.payload.model_provider`만 집계했다.
- `~/.codex/logs_2.sqlite`: 읽기 전용으로 `logs` 테이블을 조회했다. `ts` 범위와 `target`을 제한하고, 모델 필드 및 `output_item`·`sampling` 메타데이터를 집계했다.
- `~/.codex/sqlite/logs_2.sqlite`: 같은 시간 범위의 로그가 0행이었다.
- `~/.codex/config.toml`: 현재 모델·추론 수준만 확인했다.

위 숫자는 **로그 행수이며 정확한 API 요청·과금 횟수가 아니다.** 내부 Luna 실행 목적과 독립 요청 수는 이 메타데이터만으로 확정하지 못했다. JSONL의 토큰 사용 기록에도 독립 모델 필드가 없어 실제 응답 모델을 선택값만으로 단정하지 않았다. 문서·코드의 제품명 언급과 모델 목록 캐시는 호출로 세지 않았다. 감사 범위는 로컬 Codex 로그이며, 컴퓨터 전체의 외부 호출 부재를 증명하는 감사는 아니다.

감사 과정에서 로그·설정을 수정하거나 삭제하지 않았고, 외부 네트워크·모델 호출을 실행하지 않았다. 최신 판정 기준 반영을 위해 이 문서의 결론만 수정했으며 새 조사는 수행하지 않았다. 프롬프트·응답 원문, 비밀키, 전화번호, 전체 로그 메시지는 이 문서에 포함하지 않았다.
