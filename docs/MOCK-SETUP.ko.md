# 온 마을 · 대회 종료 후 로컬 시뮬레이션

2026-10-10 사용자 지시로 실제 전화·외부 AI 연동을 제거했습니다. AI API와 전화 사업자의 토큰, 운영자 토큰, 실제 전화번호는 필요하지 않습니다. 기존 환경변수나 저장된 실제 통화 데이터는 읽지 않습니다. 과거 전화 PoC의 구현과 점검 스크립트도 제거했습니다.

## 실행

```sh
npm ci
npm run build
npm start
```

서버는 기본 `127.0.0.1:8090`에서 동작합니다. `ON_PORT`로 포트를 바꿀 수 있습니다. 개발 시 `npm run dev`를 사용합니다. 브라우저 단독 시뮬레이션은 `?demo=1`을 붙여 실행하며 API 요청도 보내지 않습니다.

## 재생

화면을 열면 자동으로 산불 발생부터 대피 완료까지 재생합니다. 왼쪽에는 주민 전화 에이전트와 구조 전화 에이전트가 동시에 표시되고, 오른쪽에는 전체 48가구의 자가 대피·구조 출동·탑승·대피소 수송·차량 복귀가 표시됩니다. 통화 중에도 산불과 시계는 계속 진행합니다.

첫 통화는 반영환 할아버지(H012)의 이동 불가·구급차 요청과, 박미숙 할머니(H009)의 이미 접수된 구조 요청에 대한 반영환 대원(M01)의 출동 확인입니다. 이후 전체 주민과 대원이 28개 워크플로 분기를 차례로 재생합니다. 대화·판단·전화 연결·119 인계·이장 연결·차량 배정·위치는 모두 합성 기록입니다. 실제 전화나 음성 API는 없습니다.

각 회차는 사례를 섞되 중복 선택 때문에 일부 사례가 누락되지 않도록 구성합니다. 재질문, 청취 불가, 자가 대피, 차량 요청, 이동 불가, 응급 상황, 이장 설득, 보호자 동행, 무응답 재발신·방문, 대원 불가·재배정, 차량 없음·배차, 지연, 위험 접근, 도로 우회, 대피소 조건 확인을 모두 포함합니다. 북쪽 고립 가구 4곳에는 기존 통제 도로를 건너지 않는 명시적인 모의 우회도로를 추가했습니다.

48가구가 모두 도착하고 차량이 복귀하면 결과를 잠시 보여준 뒤 다음 회차로 넘어갑니다. 상단에서 일시정지, 12·30·60배속, 자동 반복을 조절할 수 있습니다. 기본 회차는 약 5분이며 60배속은 약 2분 30초입니다. '처음 상태로 초기화'는 지난 통화·대피 상태를 지우고 T+0에서 일시정지합니다.

완료된 대화는 각 전화 패널의 통화 내역 선택에서 확인할 수 있습니다. '전체 가구', '워크플로 사례', '상황 로그' 탭으로 전체 상태와 분기 완료를 확인합니다.

## 서버와 배포

서버는 상태와 모의 재생 명령만 처리합니다. 기존 실제 전화·토큰 부트스트랩·웹훅·오디오 경로는 HTTP 410을 반환합니다. 실행 시 기존 .env와 전화 설정 파일을 로딩하지 않습니다. 현재 상태는 메모리에 있으며 프로세스가 재시작되면 새 시뮬레이션이 시작됩니다. 브라우저와 서버 간에는 동일 출처의 `/api/state`, `/api/command`만 사용합니다.

운영 환경은 새 빌드를 재배포해야 반영됩니다. 배포 스크립트와 Docker 입력도 새 서버 구조에 맞췄으며 이전 전화·AI 비밀값을 읽거나 전달하지 않습니다. AWS 배포 도구는 수동 배포 용도로만 남아 있으며 애플리케이션 실행 경로에 포함되지 않습니다.
