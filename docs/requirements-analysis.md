# 온 마을 요구사항 분석과 mock 설계

2026-10-09 · Codex · React 19 / Node.js TypeScript

## 이번 요청의 해석

한 명의 재난 담당자가 가구의 지원 필요, 다음 조치, 자원, 미해결 인수인계를 빠르게 확인하는 상황실이다. 기존 React 디자인 스타터를 출발점으로 기능별 mock 화면을 만들고, 새 합성 JSON을 연결한다. 추가 요청에 따라 Node.js/TypeScript 서버, Telnyx 전화 모듈, 실제 LangGraph 실행 그래프를 함께 만든다.

데이터 생성 요청의 “데이터만 생성”은 JSON 제작 단계의 범위다. 이번 최상위 요청은 화면과 서버 구현까지 명시하므로 JSON 제작을 마친 뒤 별도 타입·어댑터로 연결한다. 자동 시나리오 진행을 데이터 파일에 넣지 않는다. 과거 인물·번호·판·기록을 복사하지 않는다.

## 데이터 불변식과 위험한 오해

- H=48, D=45, V=3, X=0. 방문 V는 전화 안전 분모에 넣지 않는다. 임시 제외 X는 별도 집합이며 안전 완료가 아니다.
- 발신 전: before45+visit3. 진행 중: act11+prog31+safe3=45. 후반: act3+prog2+safe40=45. 후반 인수인계는 전화 미안전5+방문3=8이다.
- 안내 되말(acked), 이동 의사, 도착 장소 근거는 서로 다르다. 단순 “네”는 안전 완료가 아니며 조원의 가능 응답과 주민 상태 판정도 구분한다.
- 119 모의 인계 기록 또는 Telnyx 연결 성공은 구조 완료가 아니다. 생성 타임아웃은 결과 불명이며 자동 재발신하지 않는다.
- 90일은 유효, 91일부터 stale. 누락·미래 날짜는 확인 필요. 같은 가구의 불명과 오래됨을 확인 필요 집계에서 중복 세지 않는다.
- 연락처는 `DEMO-CONTACT-*` 또는 null. 주소와 차량 번호도 DEMO 식별자다. 실발신 수신자 목록은 서버 환경변수에만 두고 export에서는 제거한다.
- 차량·조·운전자·가구·대피소 정원은 같은 임무 ID의 예약으로 연결한다. 복귀 차량은 가용 차량이 아니다. 통제 경로·장비·접근성·인원 불명은 출발을 허가하지 않는다.
- ETA는 D-8의 비공식 데모 식을 사용한다. 시연 구역 숫자와 동적 계산을 한 종류의 관측처럼 섞지 않는다. 실제 재난 안전 기준으로 소개하지 않는다.

## 구조와 책임

`fixtures/`는 정적 JSON 원본, `shared/src/`는 타입·집계·날짜·ETA·검증, `fe/src/`는 화면과 브라우저 mock 어댑터, `server/src/`는 Fastify API·공유 상태·예약·전화·LangGraph다. 서버가 없으면 프런트의 같은 fixture와 집계로 동작한다. 서버 연결 실패는 화면에 오프라인으로 표시하고 숨겨진 실연동 재시도를 하지 않는다.

LangGraph: 정규화→규칙 추출→근거/스키마 검증→긴급/사람검토/안내 분기→결과. 제안 흐름은 대상 스냅샷→ETA/우선순위→ID/rank검증→human review interrupt→확정 반환. 체크포인트는 로컬 메모리이며 서버 재시작 시 유실되는 한계를 명시한다. 전송/배차는 그래프 노드에 숨기지 않고 공용 서비스가 실행ID로 한 번만 적용한다.

Telnyx 모듈: demo adapter는 외부 효과0, live adapter는 공식 SDK dial/speak/hangup와 서명 검증 webhook을 사용한다. raw JSON 본문과 Ed25519·timestamp 검증, 이벤트 ID 중복 차단, 대상 allowlist·동의·이벤트확정·공용채널 상한을 검사한다. 생성 결과 불명에는 새 dial을 반복하지 않는다. 키나 실제 번호는 응답·로그·export에 포함하지 않는다. 실기기 리허설·한국 발신·음성 품질은 설정 준비 후 별도로 검증해야 한다.

## 네 가지 중요한 사용자 동작

1. 명단을 열어 출처·확인일·담당조를 확인한 뒤 감시 시작. 감시 단계는 발신0.
2. 합성 대피 지시→발령 검토→순위 수정→확정 모달. 확정 전에는 실발신·모의 발신 신규 실행0.
3. 진행 상태를 선택해 응급·거부·무응답·도움·조원·차량을 비교. 사람 결과와 모의 시스템 기록을 구분한다.
4. 통신 두절에서 방송·방문 목록을 출력하고 미안전을 인계한 뒤 종료 스냅샷/JSON 내보내기. 시나리오 선택으로 안전이 확인됐다는 의미를 만들지 않는다.

## 확인한 공식 라이브러리 자료

- [LangGraph Graph API](https://docs.langchain.com/oss/javascript/langgraph/graph-api): 상태를 공유하는 노드와 compile 실행 구조.
- [Telnyx 공식 Node SDK](https://github.com/team-telnyx/telnyx-node): 공식 클라이언트·raw body webhook 검증.
- [Telnyx Voice API webhooks](https://developers.telnyx.com/docs/voice/programmable-voice/voice-api-webhooks): 이벤트·Ed25519·시각 헤더.

라이브러리 버전은 package-lock.json에 고정한다. 원문에 쓰인 다른 서버/전화 공급자의 요청 형식을 Telnyx 형식이라고 재사용하지 않는다.
